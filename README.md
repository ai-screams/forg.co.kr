# forg.co.kr 디지털 박물관

> 한국 울티마 온라인의 가장 큰 팬사이트였던 **forg.co.kr**(1998–2016)을 그 시절 모습 그대로 다시 열어 둔 비영리 디지털 박물관입니다.

**박물관 입구:** <https://forg.co.kr>

---

## forg.co.kr은 어떤 곳이었나

**forg.co.kr**(통칭 "포그홈")은 한국 울티마 온라인(UO) 커뮤니티의 본거지였습니다. 1998년부터 2016년까지 유저들이 이곳에서 공략과 스킬 노하우를 나누고, 스크린샷과 롤플레이 이야기를 올리고, 아이템을 사고팔았습니다. 자유게시판과 질문답변 게시판에만 글이 7,600개 넘게 남아 있고, 나중에는 WoW·디아블로·리그 오브 레전드 같은 다른 게임의 게시판도 생겼습니다.

Wayback 캡처와 수집된 게시글에는 관리자 계정 **Forg**(`member_no=1`)가 반복해서 나오며, Kritz와는 `Forg&Kritz`로 함께 표기된 자매 사이트였습니다. 2006년 [진솔 비리 사건](https://namu.wiki/w/%EC%A7%84%EC%86%94%20%EB%B9%84%EB%A6%AC%20%EC%82%AC%EA%B1%B4)의 폭로 무대로도 한국 게임사에 기록된 사이트입니다.

## 왜 박물관인가

forg.co.kr은 2016년에 멈췄습니다. 그 뒤로 남은 것은 Internet Archive Wayback Machine이 그때그때 저장해 둔 캡처뿐입니다. 캡처는 글 하나, 쪽 하나씩 흩어져 있어서 주소를 알지 못하면 찾을 수 없고, 검색도 할 수 없고, 그림은 빠진 곳이 많습니다. 시간이 지날수록 그 시절을 기억하는 사람도, 옛 주소를 아는 사람도 줄어듭니다.

이 박물관은 흩어진 캡처를 모아 게시판과 글, 안내 문서로 다시 엮고, 원래 주소인 forg.co.kr에 다시 열어 둡니다. 세 가지를 목표로 합니다.

1. **그 시절 모습 그대로** — 2014·2003·2001년의 화면을 원본의 치수와 그림으로 되살립니다.
2. **남은 글을 하나라도 더** — 여러 캡처와 출처에서 모으고, 본문이 사라진 글도 목록에 남은 제목·작성자·날짜로 기록합니다.
3. **누구나 다시 찾을 수 있게** — 한글 검색을 붙이고, 다른 사이트에 남은 옛 주소가 박물관의 같은 자리로 오게 합니다.

박물관은 읽기 전용이고 비영리입니다. 광고를 싣지 않으며, 글의 권리는 각 작성자에게 있습니다.

## 박물관 둘러보기

### 시대 버튼

화면 위의 **2014·2003·2001** 버튼을 누르면 박물관 전체가 그해의 forg 모습으로 바뀝니다. 기본은 마지막 모습인 2014년(슬레이트와 골드)이고, 2003년과 2001년은 그 시절의 첫 화면과 틀로, 2001년은 게시판도 그때의 스킨으로 보여 줍니다. 첫 화면의 옛 판 쪽(`/site/index/`)에서는 2000–2010년 첫 화면 20개를 하나씩 골라 볼 수 있습니다.

### 게시판과 글

게시판 66곳을 원래의 이름으로 둡니다. 목록 1쪽 맨 위에는 공지가 서고 답글은 들여쓰기로 이어지며, 글은 원래 게시판 스킨 안에 댓글과 함께 보입니다. 되찾지 못한 그림 자리에는 빈 그림 표시가 남습니다.

- **목록만 남은 게시판** — 본문은 캡처되지 않았지만 목록 쪽이 남은 곳은 제목·작성자·날짜를 쪽 넘김과 함께 보여 줍니다.
- **회원 전용 게시판** — 손님에게 닫혀 있어 Wayback도 안내문만 저장한 곳은, 왜 비어 있는지 설명하는 쪽을 둡니다.

### 안내 문서

forg에 있던 스킬 가이드, 던전·몬스터 정보, 지도, 크래프트 재료표, 디아블로 아이템 정보, 울티마 역사, 만화, 설문 같은 문서를 원본 그대로 보여 줍니다(`/site/`). 같은 문서가 여러 번 캡처됐다면 옛 판을 골라 볼 수 있습니다.

### 검색

`/search/`에서 게시글과 안내 문서를 한글로 검색할 수 있습니다. 서버 없이 브라우저 안에서 찾습니다.

### 옛 주소

블로그나 카페에 남은 옛 forg.co.kr 링크로 들어와도 됩니다. 옛 게시글 주소, 안내 문서 주소, 그림 주소가 박물관의 같은 자리로 이어집니다.

### 휴대폰

너비 800px 이상에서는 원본의 치수를 그대로 지킵니다. 그보다 좁은 화면은 forg의 색과 디자인을 지키면서 휴대폰에 맞게 다시 짠, 박물관의 해석입니다.

## 박물관이 지키는 것

- **원본과 박물관의 말을 나눈다** — 시대 틀 안은 원본 그대로 두고, 박물관이 덧붙이는 설명은 틀 밖의 머리줄과 설명 칸에만 씁니다.
- **고치지 않고 보존한다** — 본문 글은 원본 그대로 옮깁니다. 그림 주소를 되찾은 사본으로 바꾸고, 스크립트처럼 위험한 HTML을 걸러 내는 것만 손댑니다.
- **없는 것은 없다고 말한다** — 남지 않은 글과 그림을 다른 것으로 채우지 않고, 빈자리는 빈자리로 보여 줍니다. 작성일이 남지 않은 글은 캡처 시각을 함께 적습니다.
- **모은 기록은 지우지 않는다** — 캡처와 변환한 기록은 작성자의 삭제 요청이 있을 때만 내립니다.

## 감사의 말

이 박물관은 다음 분들 덕분에 가능했습니다.

- **Forg 계정과 원 운영진** — forg.co.kr을 운영하며 한국 UO 커뮤니티의 거점을 만들어 주신 분들
- **forg.kr 후속 사이트 운영진** — 2019년 캡처에서 확인되는 후속 사이트를 유지했던 분들
- **Internet Archive** — Wayback Machine으로 인터넷의 기억을 보존
- **forg.co.kr의 모든 글쓴이** — 익명·실명을 가리지 않고 한국 UO의 추억을 글로 남겨 주신 분들
- **namu.wiki·thewiki.kr 기여자** — 한국 UO와 진솔 사건의 사료를 정리

역사 설명은 Wayback 캡처, namu.wiki, thewiki.kr, ultimastory.tistory.com과 수집된 게시글 원문을 대조해 씁니다. 1차 출처로 확인하지 못한 서술은 단정하지 않습니다.

## 만든 방법

Wayback 캡처를 Python으로 읽어 JSON으로 바꾸고, Next.js로 정적 사이트를 빌드해 Cloudflare Pages에 올립니다. 서버도 데이터베이스도 없이, 옛 주소를 잇는 작은 함수 하나만 돕니다. 개발 환경과 명령, 데이터 파이프라인은 [DEVELOPMENT.md](./DEVELOPMENT.md)에 있습니다.
